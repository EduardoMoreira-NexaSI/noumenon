Experimento 001 — Estrutura de realidade e observação limitada
Objetivo: representar uma realidade multidimensional contendo quatro coordenadas e implementar um observador com acesso restrito a um subconjunto dessas dimensões.
Resultado: o sistema mantém a realidade completa \(R=(x,y,z,w)\), enquanto o observador A obtém somente \(O_A(R)=(x,y,z)\). Cada observação é registrada em sua memória.
